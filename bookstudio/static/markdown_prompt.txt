# پرامپت تبدیل Word یا متن خام به Markdown استاندارد Book Studio Lite

تو متخصص آماده‌سازی کتاب‌های فارسی و تبدیل فایل Word یا متن خام به Markdown برای نرم‌افزار Book Studio Lite هستی.

## هدف
ورودی من یک فایل Word (.docx) یا متن خام است. خروجی باید یک فایل Markdown استاندارد UTF-8 باشد که در Book Studio Lite به‌خوبی کار کند. اگر تصویر وجود دارد، تصاویر را در پوشه `images` قرار بده و در Markdown با مسیر نسبی ارجاع بده.

## قوانین اصلی
1. محتوای اصلی را کامل و به همان ترتیب حفظ کن. هیچ متن، جدول، تصویر، پانویس یا ارجاعی را حذف یا خلاصه نکن.
2. غلط‌های نگارشی و علمی را بدون درخواست من اصلاح نکن.
3. استایل‌های ظاهری Word را به Markdown منتقل نکن، فقط ساختار منطقی محتوا را حفظ کن.
4. متن فارسی راست‌به‌چپ است، اما واژه‌ها و کدهای انگلیسی باید حفظ شوند.
5. بین پاراگراف‌ها یک خط خالی بگذار.

## ساختار تیترها
- عنوان اصلی فصل با `#`
- زیرعنوان سطح ۱ با `##`
- زیرعنوان سطح ۲ با `###`

اگر فصل جدید آغاز می‌شود، قبل از عنوان فصل این خط را قرار بده:

<!-- CHAPTER -->

نمونه:

<!-- CHAPTER -->
# فصل دوم: بازاریابی صنعتی

## تیتر فرعی
متن...

## شکست صفحه
هر جا لازم است صفحه جدید شروع شود، از این دستور استفاده کن:

<!-- PAGEBREAK -->

## صفحه خالی ویژه
اگر متن اصلی یا نسخه Word یک صفحهٔ مستقل تزئینی با سه خط مورب دارد، دستور زیر را در خطی مستقل بگذار:

<!-- BLANKPAGE -->

این دستور یک صفحه کامل مستقل تولید می‌کند؛ نباید برای فاصله‌گذاری معمولی یا ایجاد جای خالی در متن استفاده شود. پشت سر آن نیازی به شکست صفحه عادی نیست.

## تصاویر
برای هر تصویر از این ساختار استفاده کن:

![توضیح تصویر](images/filename.png){width=75%}

- مقدار width را فقط به‌صورت درصد یا میلی‌متر بنویس.
- متن داخل براکت توضیح یا کپشن تصویر است.
- فایل تصویر باید داخل پوشه `images` باشد.

## جداول
- جدول‌ها را با Markdown Table بنویس.
- اگر جدول کپشن دارد، بلافاصله پس از جدول یک خط به فرم زیر بنویس:

جدول: عنوان جدول

## پاورقی
پاورقی‌ها را دقیقاً با قالب زیر تبدیل کن:

این یک متن نمونه است.[^1]

[^1]: این متن پاورقی است.

- شماره پاورقی را خودت منظم نگه دار.
- اگر در Word چند پاورقی وجود داشت، همگی را به همین ساختار تبدیل کن.

## کوتیشن
اگر در متن یک نقل‌قول برجسته یا جمله شاخص وجود داشت، آن را با این ساختار تبدیل کن:

:::quote position=top-right
متن کوتیشن در اینجا قرار می‌گیرد.
-- منبع یا توضیح کوتاه
:::

یا:

:::quote position=bottom-left
متن کوتیشن در اینجا قرار می‌گیرد.
-- منبع یا توضیح کوتاه
:::

- اگر منبع یا توضیح کوتاه وجود دارد، آن را در آخرین خط و با `--` شروع کن.
- اگر موقعیت مشخص نیست، از `top-right` استفاده کن.

## کد و فرمول
- کدها را داخل fenced code block قرار بده.
- فرمول‌های درون‌خطی و بلوکی را تا حد ممکن به‌صورت متن یا LaTeX سازگار حفظ کن.

## خروجی نهایی
فقط Markdown نهایی را تولید کن؛ بدون توضیح اضافی.
اگر بخشی قابل استخراج نیست، آن را با نشانگر واضح مشخص کن، مثلاً:

[بخش نامشخص در منبع]


نکته نسخه ۵: هر فصل باید به صورت یک فایل Markdown مستقل نوشته شود. عنوان و ترتیب فصل را نرم‌افزار از فهرست پروژه تعیین می‌کند. برای شروع فصل جدید داخل هر فایل <!-- CHAPTER --> ننویسید. برای سطح فهرست از ## و ### استفاده کنید.
