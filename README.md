# Book Studio Lite v5.5 — خروجی PDF مطابق آخرین پیش‌نمایش

- دانلود **کل کتاب** و PDF **هر بخش** با نام شامل تاریخ، ساعت و کسری ثانیه انجام می‌شود (تکرار دانلود دیگر نام ثابت `book.pdf` ندارد).
- هر رندر موفق شناسه منحصربه‌فرد دارد. صفحه پیش‌نمایش و لینک PDF از همان شناسه استفاده می‌کنند و کش فایل‌های خروجی غیرفعال است.
- محتویات PDF دانلودی با هش فایل ساخته‌شده برای پیش‌نمایش کنترل می‌شود؛ در صورت تغییر فایل یا قدیمی‌بودن لینک، به‌جای دانلود فایل اشتباه درخواست رد می‌شود.
- پس از ویرایش یا ذخیره جدید، برای دریافت PDF ابتدا باید دوباره **پیش‌نمایش** را بسازید. اگر هنگام رندر ویرایش کنید، خروجی برای دانلود معتبر اعلام نمی‌شود.
- دکمه «دانلود PDF کل کتاب» با «PDF این بخش» متفاوت است؛ دومی فقط بخش انتخابی را تحویل می‌دهد.
- پروژه‌ها، قالب صفحات، فونت‌ها و تنظیمات موجود دست‌نخورده‌اند.

برای نصب روی نسخه ۵.۴، از پوشه برنامه پشتیبان بگیرید، برنامه را ببندید و فقط پچ چهار فایلی را در ریشه پروژه استخراج کنید. سپس برنامه را دوباره اجرا کرده و مرورگر را رفرش کنید (در صورت نیاز Ctrl+F5).

# Book Studio Lite v5.4 — اصلاح جزئی عنوان‌ها و زبانه‌ها

اصلاح‌های این نسخه: عنوان سطح `#` راست‌چین است و مثلث سمت راست با ارتفاع واقعی مستطیل (حتی برای عنوان‌های چندخطی) منطبق می‌شود. رنگ مثلث با تنظیم جداگانه در پنل تنظیمات تیترها قابل تغییر است. فاصله پیش‌فرض زبانه‌های صفحات فرد از راست/پایین، و زوج از چپ/بالا به‌ترتیب ۸ و ۱۴ میلی‌متر است.

**مهم:** تنظیمات از قبل ذخیره‌شده پروژه‌ها خودکار بازنویسی نمی‌شوند. برای اعمال فاصله‌های جدید در پروژه فعلی، مقادیر آن‌ها را از بخش تنظیمات قالب تغییر بده و ذخیره کن. پروژه آزمایشیِ نسخه کامل با مقدارهای پیش‌فرض جدید آماده است.

برای اجرای برنامه از ریشه پروژه، `python run.py` را اجرا کن. فایل‌های فونت اصلی موردنیاز را مطابق `FONT_SETUP.md` داخل `bookstudio/fonts` قرار بده.

# Book Studio Lite 5.0 — کتاب چندفایلی

این نسخه بر پایه موتور صفحه‌آرایی پایدار 4.5.3 ساخته شده است. متن کتاب در فایل‌های Markdown مستقل ذخیره می‌شود؛ تنظیمات ظاهری همچنان برای کل پروژه مشترک‌اند.

## نصب در ویندوز

1. فایل ZIP را در **پوشه جدید** استخراج کنید؛ آن را روی پروژه قبلی کپی نکنید.
2. فایل‌های Vazirmatn اصلی خود را طبق `FONT_SETUP.md` در `bookstudio/fonts/` قرار دهید. فونت‌ها به عمد در بسته موجود نیستند.
3. از پوشه اصلی پروژه دستورهای زیر را در ترمینال اجرا کنید:

```powershell
python -m pip install -r requirements.txt
python run.py
```

یا از `start_windows.bat` استفاده کنید. برای WeasyPrint روی ویندوز، کتابخانه‌های GTK/MSYS2 نیز باید طبق راهنمای نصب قبلی در دسترس باشند.

## استفاده

- ستون **ساختار کتاب**: افزودن فصل، مقدمه یا پیشگفتار و افزودن چند فایل MD از رایانه. ترتیب فصل‌های شماره‌دار با Drag & Drop تغییر می‌کند.
- **مشخصات بخش انتخاب‌شده**: عنوان، نقش بخش، و دو متن عمودی زبانه فرد فقط برای همان فایل ذخیره می‌شوند.
- **صفحات اولیه**: شناسنامه، متن تقدیم‌به، رنگ‌ها و اندازه‌ها، و تیک نمایش عناوین فصل/##/### در فهرست.
- **تنظیمات قالب**: تمام تنظیمات صفحه‌آرایی مشترک‌اند؛ «طراحی عنوان فصل» در همه فصل‌ها یکسان اعمال می‌شود. شماره شروع اولین صفحه متن Markdown را می‌توانید در بخش شماره‌گذاری تنظیم کنید.
- دکمه **پیش‌نمایش** فایل PDF کتاب کامل (شناسنامه، تقدیم، فهرست، پیشگفتار، مقدمه، فصل‌ها) را می‌سازد. پس از رندر، از گزینه **PDF این بخش** فایل انتخاب‌شده را با شماره‌های پیوسته چاپی دانلود کنید.
- دکمه **دریافت PDF** کل کتاب یکپارچه را ارائه می‌کند.

صفحات ابتدایی شماره چاپی ندارند؛ شماره‌گذاری از نخستین صفحه **متن** آغاز می‌شود و در فصل‌های بعد بدون ریست ادامه می‌یابد. صفحه عنوان اختصاصی فصل شماره چاپی ندارد اما در تقدم فیزیکی صفحات بعدی محاسبه می‌شود.

## ساختار پوشه پروژه

```text
MyBook/
  bookstudio.project.json      # ترتیب و نقش بخش‌ها و تنظیمات صفحات اولیه
  settings.json                # تنظیمات مشترک
  chapters/
    0123456789ab.md            # یک فایل Markdown برای هر بخش
    fedcba987654.md
  images/                      # تصاویر مورد ارجاع Markdown
```

متن‌های عمودی صفحات فرد در Manifest همان بخش قرار دارند، نه در تنظیمات عمومی. نام فایل‌های MD شناسه‌های ثابت است؛ عنوان قابل ویرایش فصل‌ها در manifest نگهداری می‌شود. برای تغییر ترتیب از **رابط برنامه** استفاده کنید و فایل‌ها را دستی جابه‌جا نکنید.

## باز کردن پروژه نسخه قدیمی

برنامه فایل‌های `bookstudio.project.json` نسخه ۱ را می‌خواند. اگر در `book.md` قدیمی علامت `<!-- CHAPTER -->` وجود داشته باشد، تا حد امکان متن در چند فایل مستقل تقسیم می‌شود. **قبل از باز کردن و به‌خصوص ذخیره روی همان پوشه، از پروژه قدیمی نسخه پشتیبان بگیرید.** پس از ذخیره، Manifest به نسخه ۲ ارتقا می‌یابد.

## ابزارهای Markdown

- `##` و `###`: سطوح عنوان فهرست (قابل انتخاب از تنظیمات).
- `[^1]` و `[^1]: ...`: پاورقی.
- `:::quote position=top-right` / `:::quote position=bottom-left`: کوتیشن حاشیه‌ای؛ جهت حاشیه خودکار با زوج و فرد شدن صفحه هماهنگ می‌شود.
- `<!-- PAGEBREAK -->`: شکست صفحه معمولی.
- `<!-- BLANKPAGE -->`: صفحه مستقل ویژه با سه خط مورب.
- `![عنوان](images/example.png){width=75%}`: تصویر و زیرنویس.
- جدول‌های Markdown به همراه `جدول: عنوان جدول`.

شروع فصل جدید را از **ساخت فایل فصل تازه در ستون ساختار کتاب** انجام دهید؛ نیازی نیست در هر فایل نشانگر `<!-- CHAPTER -->` بنویسید.

## v5.1 — رابط سه‌تب و بهبود صفحات اولیه

در پنل مدیریت کتاب سه تب «فصل‌ها و بخش‌ها»، «صفحات اولیه» و «تنظیمات قالب» وجود دارد. تیترهای سطح `#` نیز مثل `##` و `###` از بخش تنظیمات قالب قابل تنظیم‌اند. نشان شماره صفحه در فهرست برای عناوین سه‌گانه و مقدمه/پیشگفتار پنج رنگ مستقل دارد. متن تقدیم به و عناوین فهرست راست‌چین هستند.

## تغییرات نسخه ۵.۲

- عنوان‌های `#` به صورت کادر رنگی با مثلث متصل در سمت راست چاپ می‌شوند. رنگ کادر و متن از **تنظیمات قالب ← تیترهای داخلی** قابل تغییر است.
- رنگ پیش‌فرض `##` برابر `#575A84` با متن سفید و رنگ `###` برابر `#D1D1E0` با متن `#575A84` است.
- در **فصل‌ها و بخش‌ها ← مشخصات بخش انتخاب‌شده**، تیک «صفحه اختصاصی عنوان این بخش نمایش داده شود» برای هر فایل Markdown جداگانه ذخیره می‌شود. در صورت غیرفعال‌کردن، عنوان همچنان در اولین صفحه متن قرار می‌گیرد و تعداد صفحات، شماره صفحات فهرست و PDFهای مستقل دوباره محاسبه می‌شوند.
- پروژه‌های ساخته‌شده در نسخه‌های قبلی با مقدار پیش‌فرض **فعال** برای صفحه عنوان باز می‌شوند. رنگ‌های سفارشیِ قبلاً ذخیره‌شده به‌طور خودکار بازنویسی نمی‌شوند؛ برای رنگ‌های جدید، بخش تنظیمات تیترها را باز کرده و آن‌ها را تغییر دهید.


## متن‌های نمایشی مستقل (۵.۴)

در تب «فصل‌ها و بخش‌ها» سه متن جدید برای هر بخش وجود دارد: متن نمایشی تیتر اصلی (#)، متن بالای صفحه اختصاصی عنوان و متن پایین همان صفحه. خالی‌ماندن فیلد به معنی استفاده از عنوان اصلی یا برچسب فعلی فصل/پیشگفتار/مقدمه است. این متن‌ها بر عنوان واقعی بخش، فهرست، ترتیب فصل‌ها و شماره صفحات اثر نمی‌گذارند.
